HTML 활동지–Canva 공동 제작–Book Creator 발표–Padlet 제출을 연결한 3차시 중국 문화 프로젝트 수업

수업 설계 개요

과목중국 문화(2학년)수업 형태모둠 프로젝트 수업
프로젝트나는야! 미래의 여행 기획자 – 중국 여행 상품 개발 및 프로모션
학습목표여행 기획자가 되어 나만의 중국 여행 상품을 제안할 수 있다.
최종 산출물여행 상품 기획안 → Canva 여행상품 PPT → Book Creator 공유 자료 → 발표·동료 피드백·성찰
에듀테크 활용 흐름　작성 예시 확인 → HTML 활동지(기획·자료 탐색·누적 기록) → Canva(정보 선별·시각화) → Book Creator(공유·발표·상호 피드백)

수업 의도　학생이 여행 기획자의 역할을 맡아 중국의 지역·문화 정보를 탐색·선별하고 관광지, 문화체험, 먹거리, 교통, 숙박, 비용을 고려한 실제 가능한 여행 상품으로 재구성하도록 한다. 도구 자체보다 정보 탐색–재구성–공유–성찰의 학습 과정을 중심에 둔다.

학생 기기 운영　학생은 개인 태블릿에서 QR로 접속하며, 동일한 브라우저와 동일한 QR 주소로 다시 접속하면 작성 내용이 브라우저에 자동 저장된다. 백업 파일 저장·불러오기는 기기 변경이나 브라우저 데이터 초기화에 대비한 보조 기능으로 사용한다.

학생 「작성 예시」 탭 운영 안내

학생용 최종본 변경 사항　학생용 HTML의 1차시 앞에 「💡 작성 예시」 탭을 별도로 배치함. 학생은 예시를 확인한 뒤 「✈️ 이제 우리 모둠 여행 상품 기획하기」 버튼을 눌러 1차시 활동으로 이동함.

예시 제시 목적

완성 답안을 제공하기보다 학생이 어느 정도의 구체성으로 여행 상품을 기획해야 하는지 이해하도록 지원하는 데 목적을 둠. 예시는 작성 형식과 사고 과정을 보여 주는 비계로 활용하고, 실제 여행 정보는 모둠별로 직접 조사하도록 안내함.

교사 안내 포인트

시점교사 안내의도
1차시 도입작성 예시 탭을 2~3분간 함께 살펴보고 “장소 이름만 나열하는 것이 아니라 동선·문화체험·실현 가능성이 드러나야 한다”고 안내과제 수준 명료화
학생 기획 시작“예시의 상하이를 따라 쓰지 말고 우리 모둠의 추천 대상과 여행 테마부터 정해 보자”고 발문모방 방지·독창적 기획
자료 조사“이 정보는 언제, 어디에서 확인했는가? 실제 여행에 사용할 수 있는가?”를 확인정보 신뢰성·출처 의식
2차시 연결예시 탭의 홍보 포인트·슬로건을 다시 참고하되 모둠 상품의 핵심 매력을 스스로 선별하도록 안내Canva 시각화 연결
연구수업 관찰 포인트　예시가 학생의 정답 모방을 유도하는지가 아니라, 과제 이해 → 모둠별 질문 생성 → 실제 자료 탐색 → 여행 정보 재구성으로 이어지는 비계로 기능하는지 관찰함.

Canva 공동 제작 운영

모든 학생이 학생용 HTML의 Canva Education 초대 링크를 통해 수업 팀에 참여함. 모둠장 1명이 모둠의 PPT를 생성하고 모둠원에게 ‘편집 가능’으로 공유함. 모둠원은 각각 새 PPT를 만들지 않고 하나의 발표자료를 공동 편집함.

※ Canva 공동작업의 세부 조작 방법은 별도 「학생안내용 Canva 모둠 공동제작 방법」 PPT로 안내하고, 학생용 HTML에는 절차를 반복하여 추가하지 않음.

Canva 발표자료 마지막 장

발표자료 마지막에는 예시 자료처럼 여행상품을 한눈에 보여 주는 1장 홍보 리플렛을 제작하도록 안내함. 여행상품명·슬로건, 대표 이미지, 핵심 일정, 추천 여행지·문화체험, 먹거리, 숙박·교통 등에서 핵심 정보를 선별하여 시각적으로 재구성하게 함.

2차시Canva로 여행 상품 프로모션 발표자료 만들기

오늘 할 일　① 1차시 내용 확인·보완 → ② 핵심 홍보 포인트·슬로건 정리 → ③ Canva 모둠 공동 제작 → ④ 마지막 1장 리플렛 완성 → ⑤ HTML 저장

수업 운영: 모든 학생이 Canva Education 수업 팀에 참여한 뒤, 모둠장 1명이 PPT를 생성하여 모둠원에게 ‘편집 가능’으로 공유함. 모둠원은 같은 PPT에서 역할을 나누어 공동 제작함.

교사 지원학생 활동관찰 초점
예시 발표자료와 Canva 공동작업 안내 PPT 제시, 필요한 경우 자료 탐색·출처 확인 지원 HTML 조사 내용을 검토하고 부족한 정보를 보완한 뒤, 사진·지도·이동 동선·일정·먹거리·홍보 문구를 선별하여 발표자료로 재구성함. 마지막 장에는 여행상품 1장 홍보 리플렛을 제작함. 자료를 단순 복사하는지보다 정보를 선별·보완하고 목적에 맞게 시각적으로 재구성하는 과정, 모둠 내 역할 분담과 공동 편집 과정에 초점을 둠.
리플렛 안내 문구　“발표자료 마지막 장에는 예시처럼 우리 모둠의 여행상품을 한눈에 보여 주는 1장 홍보 리플렛을 만들어 주세요.”

3차시Book Creator 공유 및 여행 상품 발표

오늘 할 일　① Canva 발표자료 PDF 준비 → ② Book Creator 업로드·발표 → ③ 다른 모둠 발표 피드백 → ④ HTML 성찰 작성 → ⑤ 최종 저장 → ⑥ 개인 활동기록 PDF 생성·Padlet 제출
단계학생 활동교사 확인
발표 준비모둠의 Canva 발표자료를 PDF로 저장하고 Book Creator에 업로드발표자료와 마지막 1장 리플렛 완성 여부
발표·공유여행상품의 테마, 주요 일정, 문화체험, 먹거리, 홍보 포인트를 중심으로 발표정보의 타당성, 설명의 명료성, 모둠 협력
동료 피드백다른 모둠의 상품을 보고 가장 가보고 싶은 상품과 이유 기록구체적 근거가 드러나는지 확인
성찰새롭게 알게 된 지역·문화적 특징, 자신의 역할과 기여, 보완점을 HTML에 작성활동 과정과 학습 내용이 연결되는지 확인
최종 제출HTML 개인 활동기록 PDF를 생성하여 해당 합반 Padlet에 제출반·번호·이름 및 최종 PDF 첨부 여부 확인

📚 3차시 | Book Creator 발표 라이브러리 연결

교사용 바로가기　Canva 발표자료를 PDF로 저장한 뒤, Book Creator 라이브러리에서 모둠별 자료를 공유하고 발표합니다.

3차시 운영 절차

  1. 모둠별 Canva PPT 완성 후 PDF로 다운로드
  2. 위 버튼을 눌러 Book Creator에 접속하고 필요시 로그인·학생 참여 진행
  3. 모둠당 발표자료 1개를 공유하고 여행 상품 발표
  4. 학생용 HTML에서 동료 피드백·성찰을 작성한 뒤 개인 활동기록 PDF를 Padlet에 제출
연구회 공유 시 유의　이 버튼은 실제 수업 라이브러리의 학생 참여 코드가 포함된 초대 링크입니다. 연구회 공개용으로 배포할 때는 참여 코드 노출 및 외부 참여 가능성을 고려하여 링크를 제거하거나 교사 전용 자료로 공유하세요.

※ 학교 와이파이에서 Book Creator 사이트 자체가 열리지 않으면 초대 링크 변경만으로 해결되지 않으며 학교 네트워크 접속 설정을 확인해야 합니다.

과정중심평가 및 연구수업 관찰 초점

관찰 영역관찰 내용
기획·자료 탐색실제 여행이 가능한 관광지·교통·숙박·식당·비용 정보를 신뢰할 수 있는 자료에서 탐색하고 출처를 기록하는가
정보 조직여행 테마와 추천 대상에 맞게 일정·동선·문화체험·먹거리를 논리적으로 구성하는가
정보 재구성HTML에 수집한 정보를 Canva 발표자료와 1장 리플렛의 목적에 맞게 선별·요약·시각화하는가
협업Canva 공동 편집 과정에서 역할을 나누고 하나의 여행상품을 완성하기 위해 의견을 조정하는가
공유·피드백Book Creator 발표를 통해 여행상품의 특징을 명료하게 전달하고 다른 모둠의 결과물에 근거 있는 피드백을 제시하는가
성찰중국의 지역·문화적 특징, 자신의 역할과 기여, 개선점을 구체적으로 기록하는가
에듀테크 활용의 관찰 관점　도구 사용 능력 자체보다 HTML의 정보 조직 → Canva의 선별·시각화·공동 제작 → Book Creator의 공유·발표 → Padlet의 결과 제출로 학습이 어떻게 확장되는지에 초점을 둠.
